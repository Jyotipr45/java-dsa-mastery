# Data Structures and Algorithms

Topics are numbered in the suggested learning order, so you can work through them from `01` upward. Each topic has its own folder with a guide (`README.md`) and practice problems grouped by difficulty. Problems are numbered from `001` within each difficulty folder.

Follow the [learning roadmap](../ROADMAP.md) for a suggested order, or jump to any topic you want to practice.
